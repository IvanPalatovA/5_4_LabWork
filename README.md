# Лабораторная работа 4

## Описание
В работе реализованы два механизма защиты от состояний гонки при работе с базой данных PostgreSQL, написана Alembic-миграция с ограничениями и скрипт-доказательство.

## Требования
- Python 3.12
- Docker (с запущенным PostgreSQL 16)
- Установленные зависимости: `pip install "sqlalchemy>=2.0" psycopg2-binary alembic`
